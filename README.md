# freeTask
turn scheduling and completing chores into a game

Entirely FOSS!
Every time you complete a task, you get more free time added in your TEMPORAL BANK which you can use to do whatever you want. Once this time is over, it will continously beep and annoy you 
to motivate you into doing your tasks.

This tool comes with some themes, I will add more in the future. If you make your own please add them to this repo.
